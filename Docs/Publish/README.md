# Publish

`mdu render` writes a folder of static files that any web server can host. Pick the guide for your platform:

- [GitHub](./GitHub.md) - Publish with GitHub Pages and the MDU action
- [GitLab](./GitLab.md) - Publish with GitLab Pages and GitLab CI/CD
- [Custom](./Custom.md) - Render the site and upload it anywhere
- [Confluence](./Confluence.md) - Publish an edit-protected mirror to a Data Center space or page subtree

> [!TIP]
> Fetch the full git history in CI so that pages can show their [last changed date](../Features/Navigation.md#page-footer).
