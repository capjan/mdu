# Features

Everything on these pages is written in ordinary Markdown. Each page shows the source with the rendered result below it, so you can copy what you need.

## Write

- [Formatting](Formatting.md) - Headings, emphasis, lists, links, and collapsible sections
- [Abbreviations](Abbreviations.md) - Page-local and shared glossary tooltips
- [Code Blocks](CodeBlocks.md) - Syntax highlighting, titles, copy buttons, and results
- [Tables](Tables.md) - Column alignment and formatting inside cells
- [Callouts](Callouts.md) - Notes, tips, and warnings with GitHub's alert syntax
- [Footnotes](Footnotes.md) - Numbered notes with hover previews
- [Keyboard Keys](./Keyboard-Keys/README.md) - Shortcuts such as ++cmd+s++ drawn as keycaps

## Illustrate

- [Diagrams](Diagrams.md) - Mermaid, PlantUML, context, and isometric diagrams as static SVG
- [Math](Math.md) - GitHub-compatible formulas as static SVG
- [Icons and Emojis](Icons-and-Emojis.md) - Thousands of icons, colored logos, and emoji shortcodes
- [Images](Images.md) - Local and remote images with a zoomable viewer
- [Media Links](MediaLinks.md) - Direct MP4 playback and YouTube and Vimeo players that load only with consent
- [Hero Banner](Hero.md) - Try theme-aware animated backgrounds, live controls, and your own shaders

## Organize

- [Navigation](Navigation.md) - Sidebar, top tabs, breadcrumbs, ordering, and the page footer
- [Dashboard](Dashboard.md) - A start page of link tiles with logos, filter, and web search
- [Tags](Tags.md) - Connect pages across sections with tag pages and a checked vocabulary
- [Tags](Tags.md) - Connect pages across sections with tag pages and a checked vocabulary

## Compose

- [Repository Imports](Repository-Imports.md) - Combine Markdown pages from multiple Git repositories

## Document APIs
